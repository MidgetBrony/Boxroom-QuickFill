# BOXROOM Quick Fill 1.0.0

- Fill the shelf you are looking at by pressing **O**.
- Preserve existing shelf contents and fill only available spaces.
- Add eligible media in A-Z order without duplicating items already spawned, held, or reserved by a source box.
- Filter by games, albums, movies/videos, books, installed BR-MediaAPI types, or all shelf-compatible media.
- Configure the shortcut and media type through ModsPanel.
