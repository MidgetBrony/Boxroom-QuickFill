# BOXROOM Quick Fill 1.1.0

- Added a Steam content filter with Games only, Games and DLC, DLC only, and All Steam content choices.
- Added a separate tools and utilities filter with exclude, include, and tools-only choices.
- Dedicated servers, SDKs, editors, runtimes, and Proton utilities are recognized even when Steam reports them as games.
- Games-only filling now excludes DLC and tools by default.
